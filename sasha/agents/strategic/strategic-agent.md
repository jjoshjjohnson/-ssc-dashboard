## DECISION FRAMEWORK

When evaluating a strategic question:
1. Does this accelerate first revenue? → Priority 1
2. Does this reduce costs or increase margin? → Priority 2
3. Does this build long-term moat? → Priority 3
4. Does this distract from #1? → Defer or kill

Israel rule: Always factor 0% VAT on export services into margin calculations. This makes US/EU client targeting structurally superior to domestic Israeli work.
